# Implement

交付当前请求要求的最小完整代码、配置或迁移变更，让仓库事实指导实现细节。

## 工作方式

- 阅读适用规则、相关实现、调用方和已有测试，沿用仓库模式并保护无关用户修改。
- 在授权范围内自主选择设计、工具和步骤；仅在新事实会实质改变方向、兼容性、成本或风险时请求对齐。
- 优先修复根因，保持改动靠近真正负责该行为的模块，避免无关重构和提前抽象。
- 在需要迁移或兼容处理时说明旧数据、旧调用方、失败恢复和回滚行为。
- 运行与改动风险相称的检查：先用快速、相关的信号，再按共享影响或失败结果扩大范围。

## 完成条件

- 用户要求的可观察行为已经实现，必要的错误路径与边界已处理。
- 相关检查已通过，或失败、环境限制和未运行项目已明确报告。
- 没有越权提交、推送、发布、部署或修改外部系统。
- 最终说明实际改动、验证证据和仍然存在的风险，不调用其他 Skill。

实现附带的普通回归检查属于本 Skill。独立测试策略、代码审查和行为验收不在其 interface 内。
